# Third-party components

Camera Compositor uses existing libraries to run the camera, detect subjects, and track the view as the phone moves. The app's own framing rules combine those results to decide whether to suggest a shot. The main composition feature runs on the phone and works offline.

## Camera and tracking

- **Google CameraX 1.6.2** opens the camera, displays the preview, supplies frames for analysis, and handles focus, zoom, and JPEG capture. Its Camera2 backend talks to the phone's camera hardware. The Extensions module lets the app use manufacturer Auto, HDR, or Night processing when the selected camera exposes those modes. [Camera setup](../app/src/main/java/dev/cameracompositor/MainActivity.kt), [photo modes](../app/src/main/java/dev/cameracompositor/CameraQuality.kt), [AndroidX source and Apache 2.0 license](https://github.com/androidx/androidx).
- **AndroidX Activity and Core** provide the Android activity, camera permission prompts, and compatibility helpers for the camera screen. [App dependencies](../app/build.gradle.kts), [AndroidX source and Apache 2.0 license](https://github.com/androidx/androidx).
- **OpenCV 4.12.0** tracks the proposed shot after it appears. The tracker follows distinctive image points between preview frames and checks that enough of them agree before moving the outline. It can search for matching features again if it loses the target. [Tracking code](../app/src/main/java/dev/cameracompositor/SceneTracker.kt), [source and Apache 2.0 license](https://github.com/opencv/opencv/tree/4.12.0).
- **Android's rotation-vector sensor** supplies the orientation used to draw the viewfinder level. Automatic capture uses the level reading alongside image tracking and the steady hold. [Sensor code](../app/src/main/java/dev/cameracompositor/MotionOrientation.kt), [level calculation](../app/src/main/java/dev/cameracompositor/CameraLevel.kt).

## Models that run on the phone

- **Microsoft ONNX Runtime 1.23.2** loads the exported model files and runs them on the phone's CPU. ONNX is the format that stores each model. Runtime is the library that executes it. The app disables runtime telemetry. [Versioned source and MIT notices](https://github.com/microsoft/onnxruntime/tree/v1.23.2).
- **NanoDet Plus** finds boxes around recognizable subjects in one camera frame. A person's box can help the planner keep them inside the suggested composition. The packaged model comes from the pinned Apache 2.0 OpenCV Zoo distribution. Its export keeps the trained weights fixed so ONNX Runtime can optimize the model. [Pinned model and license](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/object_detection_nanodet).
- **TinyCLIP ViT-8M** compares small regions of the image with fixed concepts such as trees or buildings. This gives the planner evidence for scenes where a single object box would miss the subject, such as a skyline. The export includes the image encoder and precomputed concept vectors. The APK includes the upstream MIT notice. [Pinned weights and model card](https://huggingface.co/wkcn/TinyCLIP-ViT-8M-16-Text-3M-YFCC15M/tree/a2a8c6eaa2549ad66eb7c31b85022bf58273a26c), [upstream code notice](https://github.com/microsoft/Cream/blob/main/TinyCLIP/LICENSE).
- **GAIC** rates candidate framings by comparing proposed rectangles within the current image. In the private Vivo rehearsal build, the app combines that score with its own checks for subject coverage, scene layout, and zoom. The dynamic export is in `.local/vivo-demo-assets` and the older fixed-input export is in `.local/research-assets`. Release builds exclude both. [Framing code](../app/src/main/java/dev/cameracompositor/AdaptiveFraming.kt), [author's source](https://github.com/HuiZeng/Grid-Anchor-based-Image-Cropping-Pytorch), [GAIC code notice](../research/GAIC-LICENSE.txt).
- **ZipDepth** estimates which parts of an ordinary RGB image are closer or farther away. The research sweep can use those relative estimates to compare views where foreground clutter obscures the subject. The project converts the pinned mobile checkpoint to ONNX locally and bundles its MIT notice. [Sweep planner](../app/src/main/java/dev/cameracompositor/LocalComposition.kt), [pinned source, weights, and license](https://github.com/fabiotosi92/ZipDepth/tree/91f3fd21e131641f51e8d35736d1958350180e3a).

## Optional Google experiments

- **Google ARCore 1.57.0** powers the separate spatial test under Developer tools. It uses Google Play Services for AR to sample the phone's position and orientation, tracked points, and depth on supported devices. The probe uses a local AR session and includes an in-app disclosure and `ARCore-NOTICE.txt`. [Probe code](../app/src/main/java/dev/cameracompositor/SpatialProbeActivity.kt), [ARCore terms](https://developers.google.com/ar/develop/terms), [privacy requirements](https://developers.google.com/ar/develop/privacy-requirements).
- **Google Gemini and OkHttp 4.12.0** power the optional cloud scene scan. With the user's consent and personal API key, the app sends images to Gemini for a structured framing suggestion. OkHttp handles the network request, cancellation, and timeouts. Gemini runs on Google's servers under the user's account and provider terms. [Cloud setup](AI_SETUP.md), [OkHttp source and Apache 2.0 license](https://github.com/square/okhttp/tree/parent-4.12.0).

## Build, research, and tests

- **Kotlin 2.3.20** is the Android app's language. **Gradle 8.11.1**, the **Android Gradle Plugin 8.10.1**, and the Android SDK compile and package it. The Windows setup installs JDK 21, and the app targets Java 17 bytecode. Android Studio can open and run the Gradle project. [Build instructions](../README.md#build), [Kotlin source and notices](https://github.com/JetBrains/kotlin/tree/v2.3.20/license).
- **JUnit** runs the Android unit tests, including level math, countdown rules, subject retention, and zoom limits. **MockWebServer** simulates network failures such as a slow reply or a quota error. **org.json** supports parsing in desktop JVM tests. **Android lint** checks the code and resources for issues such as incompatible API usage. [Test code](../app/src/test/java/dev/cameracompositor), [test dependencies](../app/build.gradle.kts).
- **Python 3.12** runs the desktop research scripts. **PyTorch** and **Transformers** load checkpoints for model export, and **ONNX Runtime** checks the exports on desktop. **TensorFlow/Keras** runs the older NIMA aesthetic-ranking experiment. **NumPy** and **SciPy** prepare inputs and measure results. **Pillow** and **OpenCV for Python** process replay images and help generate the research comparisons. [Research workflow](../research/README.md), [Python dependency lock](../research/requirements-lock.txt).
