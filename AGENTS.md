# Project instructions

- Do not use em dashes or litotes in user-facing writing.
- The owner leads UI/UX. Keep engineering scaffolding visually plain until the owner supplies a design.
- Before making UI, search for recognizable AI-generated UI patterns and avoid them across color, gradients, layout, style, and typography.
- For Roblox work, use Builder Sans by default unless the owner specifies a font. This project currently targets native Android.
- Android first; primary test phone is a Vivo V30 (standard model).
- Favor responsive on-device processing and explain development steps for an owner new to app development.
- Keep camera/model logic separate from framing rules and viewfinder drawing.
- After code changes, run the relevant build, composition unit tests, and Android lint. Record physical-device results honestly.
